LÍDER ENCANTADORA — INTEGRAÇÃO FIREBASE (ETAPA DE TESTE)

O QUE ESTA VERSÃO FAZ
- Lê os produtos do Cloud Firestore e atualiza a vitrine em tempo real.
- Permite entrar no painel com e-mail e senha do Firebase Authentication.
- Cadastra, edita e exclui produtos no Firestore.
- Sincroniza configurações da loja entre aparelhos.
- Mantém o carrinho no navegador do cliente.
- Permite selecionar fotos da galeria. As fotos são comprimidas e guardadas no próprio documento do produto no Firestore, sem usar Firebase Storage.
- Mantém pedido pelo WhatsApp e confirmação de Pix manual.

CONTA ADMINISTRADORA DE TESTE
As regras incluídas autorizam somente o e-mail:
hrproplay@gmail.com

Se o e-mail administrativo for outro, altere esse endereço em DOIS lugares:
1. app.js, na constante ADMIN_EMAILS.
2. firestore.rules, na função isStoreAdmin().
Os dois endereços precisam ser exatamente iguais.

ANTES DE PUBLICAR — FAÇA ISTO NO FIREBASE
1. Abra Firebase Console > Authentication > Usuários.
2. Confirme que hrproplay@gmail.com aparece na lista e que você sabe a senha definida para essa conta.
   - Se não souber a senha, use a opção de redefinição de senha do Authentication ou crie outro usuário de teste.
3. Abra Cloud Firestore > Segurança > Editar regras.
4. Substitua TODO o conteúdo das regras pelas linhas do arquivo firestore.rules deste pacote.
5. Clique em Publicar.
6. Não altere nem habilite o Firebase Storage. Esta versão não depende dele.
7. Em Authentication > Método de login, confirme que E-mail/senha está ativado.

PUBLICAÇÃO NO GITHUB PAGES
1. Extraia este ZIP.
2. No repositório GitHub, substitua os arquivos index.html, app.js, style.css, manifest.json, sw.js e icon.svg pelos arquivos deste pacote.
3. Envie também o arquivo firestore.rules e este LEIA-ME.txt. O arquivo de regras é uma referência para copiar no console; o GitHub Pages não publica as regras automaticamente.
4. Aguarde o GitHub Pages concluir a publicação.
5. Abra o endereço do site no Chrome e atualize a página. Se o app instalado mostrar a versão antiga, feche-o completamente e abra o endereço no Chrome novamente.

LIMITES IMPORTANTES
- Esta etapa sincroniza catálogo e configurações com o Firestore.
- As imagens são comprimidas e armazenadas junto aos documentos Firestore. Use fotos pequenas. O Firestore tem limite de tamanho por documento (1 MiB); esta versão limita a imagem para reduzir o risco, mas não é um sistema de armazenamento de imagens em grande escala.
- O pedido continua sendo encaminhado pelo WhatsApp. Não há pagamento Pix automático nem reserva automática de estoque.
- A regra permite leitura pública da vitrine e escrita somente para hrproplay@gmail.com. Não compartilhe a senha dessa conta.
- A chave web apiKey do Firebase identifica o projeto, mas não substitui as regras de segurança.
- Teste primeiro com um produto sem dados sensíveis antes de divulgar a loja.
