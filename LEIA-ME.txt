LÍDER ENCANTADORA — FIREBASE + CLOUDINARY

O QUE ESTA VERSÃO FAZ
- Lê produtos do Cloud Firestore e atualiza a vitrine em tempo real.
- Usa Firebase Authentication para o acesso administrativo.
- Cadastra, edita e exclui produtos no Firestore.
- Sincroniza configurações da loja entre aparelhos.
- Envia fotos novas ao Cloudinary usando upload preset unsigned; grava no Firestore somente a URL segura da imagem.
- Comprime as fotos no navegador e aceita JPG, PNG e WEBP de até 5 MB antes da compressão.
- Mantém o carrinho no navegador do cliente.
- Encaminha pedidos pelo WhatsApp; pagamento e confirmação do Pix continuam manuais.

CLOUDINARY CONFIGURADO NO CÓDIGO
- Cloud name: zcbedlgt
- Upload preset: lider_encantadora
- Pasta definida no preset: lider_encantadora/produtos
- Modo: Unsigned

IMPORTANTE SOBRE SEGURANÇA DO CLOUDINARY
O preset unsigned é público por natureza. A validação de formato e tamanho feita no navegador melhora o uso normal, mas não impede que terceiros tentem enviar arquivos diretamente à API. No painel Cloudinary, edite o preset lider_encantadora e configure também no servidor: Allowed formats = jpg,jpeg,png,webp; Max file size = 5242880 bytes (5 MB), se esses campos estiverem disponíveis. Não coloque API Secret no app.js. Monitore o uso/créditos da conta.

PUBLICAÇÃO NO GITHUB PAGES
1. Extraia este ZIP.
2. Substitua no repositório os arquivos index.html, app.js, style.css, manifest.json, sw.js e icon.svg pelos arquivos deste pacote.
3. Mantenha firestore.rules como referência e confira no Console do Firebase se as regras publicadas autorizam hrproplay@gmail.com. O arquivo não publica regras automaticamente.
4. Aguarde o GitHub Pages concluir a publicação.
5. Abra o site no Chrome e atualize. Se o app instalado mostrar a versão antiga, feche-o completamente e abra o site novamente. O cache do service worker foi atualizado para v3.

LIMITES
- A integração Cloudinary foi adicionada ao código, mas precisa ser publicada no GitHub Pages para entrar em funcionamento no site público.
- Produtos e configurações usam Firestore; imagens novas usam Cloudinary. Imagens antigas em base64 continuam sendo exibidas, mas não são migradas automaticamente.
- Não há pagamento Pix automático, gateway de cartão, baixa automática de estoque nem gestão completa de pedidos.
- Não compartilhe a senha administrativa. A apiKey web Firebase não substitui as regras de segurança.
