LÍDER ENCANTADORA — ATUALIZAÇÃO DO PAINEL 2.1

O QUE FOI ADICIONADO
- Painel com abas: Dados da loja, Produtos e Pedidos.
- Cadastro de produtos no Firestore.
- Edição e exclusão de produtos.
- Campos de nome, categoria, descrição, preço, preço promocional, tamanhos, cores, estoque e URL pública da foto.
- Lista de pedidos recebidos e atualização de status.

ARQUIVOS ALTERADOS
- painel.html
- painel.js

Os demais arquivos foram preservados do ZIP original.

COMO PUBLICAR
1. Faça uma cópia de segurança do repositório atual.
2. No repositório GitHub da loja, substitua SOMENTE painel.html e painel.js pelos arquivos deste pacote.
3. Faça commit das alterações e aguarde o GitHub Pages publicar.
4. Abra https://hangel-15.github.io/lider_encantadora/painel.html
5. Entre com o e-mail autorizado hrproplay@gmail.com e a senha já cadastrada no Firebase Authentication.
6. Teste primeiro o cadastro de um produto de teste com preço e estoque corretos; depois confira se ele aparece na vitrine.

IMPORTANTE SOBRE FOTOS
Este painel recebe um link público da foto. Ele ainda não faz upload de arquivos diretamente para o Cloudinary. Use URLs públicas de imagens já hospedadas.

IMPORTANTE SOBRE FIREBASE
O painel depende do projeto Firebase já configurado no código (lider-encantadora-2c99c).
As regras firestore.rules deste pacote original permitem ao administrador criar/editar/excluir produtos e consultar/atualizar pedidos. Confirme no Firebase Console > Firestore Database > Regras se essas regras estão publicadas.
A conta administrativa autorizada no código é hrproplay@gmail.com. A senha não está incluída neste pacote.

LIMITAÇÕES
- Não há pagamento online automático; Pix continua combinado manualmente.
- O painel atualiza status de pedidos, mas não inclui baixa automática de estoque.
- Fotos são informadas por URL; não há upload direto pelo painel nesta versão.
- Esta atualização não altera a loja pública nem apaga produtos já cadastrados.
